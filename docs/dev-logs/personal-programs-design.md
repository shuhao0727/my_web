# 个人程序（应用中心） - 开发设计文档（简化版）

## 一、项目概述

### 1.1 项目定位
- **名称**: 个人程序（应用中心）
- **定位**: 登录保护的个性化应用集合，为学生和教师提供学习工具和实用程序
- **目标用户**: 学生、教师、需要专用工具的用户
- **核心价值**: 提供安全的、个性化的应用访问入口，集成学习工具和实用程序

### 1.2 核心功能
- ✅ **登录保护**: 使用XBK用户认证系统，确保只有授权用户可访问
- ✅ **应用展示**: 静态展示预设应用卡片
- ✅ **直接访问**: 支持外部URL直接跳转
- ✅ **后台管理**: 管理员可管理用户数据

### 4.4 登录保护流程
1. 用户访问 `/personal-programs`
2. 检查localStorage中的xbk_user信息
3. 有有效用户信息 → 显示静态应用卡片
4. 无有效用户信息 → 显示登录提示和登录模态框
5. 登录成功 → 保存用户信息到localStorage，显示应用卡片
